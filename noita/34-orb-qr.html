The 34-Orb QR Code

A QR code overlaid with structured noise, loaded into memory when you get the 34th orb, with its first pixel inexplicably flipped.

Unsolved

What We Know

Inside the '34 orb end credits' blob in the executable, Kaliuresis found the phrase 'Kiitoksia kaloista!' ('So long, and thanks for all the fish', a Hitchhiker's Guide reference) and a QR code overlaid with noise.

Scanning the QR opens a page on noitagame.com. The overlaid noise is not from any known generator: some rows match other rows in specific colour channels.

Getting the 34th orb loads the QR into memory for the rest of the run, and it persists into a new run until the game process restarts. On load, its very first pixel is changed to white. The 34-orb credits screen itself never actually appears.
